OpenVolley eScoresheet

The electronic scoresheet for indoor and beach volleyball. Score on a laptop or tablet, and let referees, benches and fans follow the match live.

  • Browser, Windows, Linux and Android
  • Works offline in the hall
  • Free, GPL-3.0

Apps

Everything around the match

Each app runs in the browser – open it on the device that needs it.

Indoor volleyball

OpenVolley eScoresheet

  • eScoresheet app.openvolley.app Score a match: match setup, rosters, coin toss, rallies, sanctions and signatures.
  • Referee dashboard referee.openvolley.app The live match on a tablet or phone for the 1st and 2nd referee.
  • Bench dashboard bench.openvolley.app The live match for the team bench.
  • Roster upload roster.openvolley.app Teams send their roster to the scorer before the match.
  • Livescore livescore.openvolley.app Follow a match live from anywhere.
  • Scoresheet archive scoresheet.openvolley.app Finished matches and their scoresheets.
  • Manager manager.openvolley.app Accounts, invite codes, official games and saved teams, for admins and competition managers.

Beach volleyball

OpenBeach eScoresheet

  • eScoresheet beach.openvolley.app Score a beach volleyball match.
  • Referee dashboard referee-beach.openvolley.app The live match for the referees.
  • Livescore livescore-beach.openvolley.app Follow a beach match live from anywhere.
  • Scoresheet archive scoresheet-beach.openvolley.app Finished beach matches and their scoresheets.

Install the eScoresheet

For the scorer’s table, also without internet. The desktop app serves the referee, bench and livescore dashboards to tablets on the hall network.

Windows

64-bit installer

Download and run the installer. Windows may show a SmartScreen notice for a new app: “More info” → “Run anyway”.

Download for Windows

Linux

Debian, Ubuntu, Mint · APT

Install with one command from the signed APT repository. Updates come with the system updates.

Install on Linux

Android

Tablets · F-Droid or APK

Add the OpenVolley repository to F-Droid for automatic updates, or install the APK directly.

Install on Android

All packages, signing keys and fingerprints are on get.openvolley.app. Source code on GitHub.
